ftnMDReader — Changelog
=======================

v1.0.8
------
- Moved line numbers to the left (their usual position) — v1.0.7 put
  them on the right by mistake.


v1.0.7
------
- Added line numbers in Edit mode, placed on the right edge of the
  editor (CodeMirror puts them on the left by default; moved here via
  a flex-order override). The active line's number is highlighted too,
  matching the active-line highlight added last version. Not available
  in the plain-textarea fallback if the CodeMirror CDN is unreachable.


v1.0.6
------
- Added a cursor position indicator ("Ln 12, Col 4") next to the
  filename, updating live as you type or move around — hidden in
  Preview-only mode since there's no cursor to show there.
- The current line is now subtly highlighted in the editor, making it
  easier to keep your place in longer files.


v1.0.5
------
- Replaced the plain <textarea> editor with CodeMirror 6, loaded from a
  CDN. This is a bigger change under the hood than it looks:
  * Ctrl/Cmd+D is now TRUE multi-select — repeat it to select and edit
    several occurrences at once, not just jump to the next one.
  * Tab / Shift+Tab now indent and unindent, which plain <textarea>s
    never supported (Tab used to just move focus away).
  * Syntax highlighting in Edit mode now runs on a real markdown parser
    instead of the old regex-based approximation — handles nested
    formatting and edge cases far more reliably.
  * Undo/redo, line wrapping, and Alt+Shift+Down (duplicate line) all
    still work as before, just backed by CodeMirror's own commands now.
  Known trade-off: the editor itself now depends on that CDN load
  succeeding (previously only Preview's code-block coloring did). If
  it can't be reached, editing still works via an automatic plain-
  textarea fallback, just without syntax highlighting or multi-select.
  Also, task-list checkboxes ("- [ ]" vs "- [x]") no longer get a
  distinct checked/unchecked color in Edit mode — a minor cosmetic
  regression versus the old hand-rolled highlighter.


v1.0.4
------
- Ctrl/Cmd+D: with text selected, jumps to the next occurrence of that
  text (wraps to the start of the document); with no selection, selects
  the word under the cursor first. Note: since a plain textarea only
  supports one selection at a time, this is "select next match" rather
  than true multi-cursor editing like VS Code/Sublime.
- Alt+Shift+Down: duplicates the current line, moving the cursor (or
  selection) down to the same position on the new copy.


v1.0.3
------
- Added dark mode: a 🌙/☀️ toggle in the topbar switches the whole app's
  palette. The saved preference is applied before first paint (no flash
  of the wrong theme), and code blocks in Preview/export stay their
  usual dark treatment regardless of the app theme. All color pairings
  were checked against WCAG contrast minimums.


v1.0.2
------
- Added zen mode: a distraction-free writing view that hides the topbar,
  sidebar, toolbar, doc header, and footer, leaving just the editor
  (and preview, in Split/Preview) centered at a comfortable reading width.
  Toggle with Ctrl/Cmd+Shift+F or the ⛶ button next to Rename; exit with
  Esc, the same shortcut, or the small floating button in the corner.


v1.0.1
------
- Added this changelog, linked from the footer next to the version number.


v1.0.0
------
Initial release. Includes:

- Open a local folder and browse its markdown files/folders in a tree sidebar
- Create, rename, move, and delete files and folders
- Drag and drop (or the "Move to folder…" picker) to move files between folders
- Full markdown editor with live syntax highlighting and a formatting toolbar
  (headings, bold/italic/strikethrough, lists, task lists, quotes, links,
  images, tables, code blocks, horizontal rules)
- Undo/redo fully integrated with the formatting toolbar, plus dirty-state
  tracking that clears correctly when undoing back to the saved text
- Edit / Preview / Split views, with a resizable divider in Split mode
- Live-rendered preview with per-language code syntax highlighting
  (highlight.js) and a one-click "Copy" button on code blocks
- Filename search and optional full-text search across all files, plus a
  quick-open command palette (Ctrl/Cmd+K)
- Remembers the last opened folder between sessions (with a reconnect
  prompt, since browsers require a fresh permission grant each session)
- Resizable, collapsible sidebar
- Export the current file to PDF (via the browser's print dialog) or to a
  self-contained standalone HTML file
- Folder path shown in the footer, with a copy-to-clipboard button
- Keyboard shortcuts reference card (PDF), linked from the footer
- Help modal with app info, accessible from the topbar or the empty state
- A "Close" button to return to the empty state without opening another file
